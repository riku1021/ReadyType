# ファイル日本語翻訳スキル

$ARGUMENTS

---

以下のルールに従って、指定されたファイルまたはディレクトリの内容を日本語に翻訳してください。

## Step 1: 入力パスの検証

1. `$ARGUMENTS` で指定されたパスを解決する。相対パスの場合はカレントディレクトリを基準に絶対パスに変換する
2. Bash の `ls -ld` コマンドでパスの存在とタイプ（ファイル/ディレクトリ）を確認する
3. 以下の場合はエラーメッセージを表示して終了する:
   - パスが存在しない場合
   - パスがシンボリックリンクの場合

## Step 2: モードの判定と出力先の決定

### ファイルモード（パスがファイルの場合）

単一ファイルを翻訳する。出力ファイル名は元のファイル名の**最後の拡張子の前**に `.ja-JP` を挿入する。

| 元のファイル | 出力ファイル |
|------------|------------|
| `readme.md` | `readme.ja-JP.md` |
| `config.prod.json` | `config.prod.ja-JP.json` |
| `LICENSE`（拡張子なし） | `LICENSE.ja-JP` |

出力先は元のファイルと同じディレクトリ。**出力先ファイルがすでに存在する場合、そのファイルの翻訳はスキップする。**

### ディレクトリモード（パスがディレクトリの場合）

ディレクトリ内の翻訳対象ファイルをすべて翻訳する。

- 出力先: 元のディレクトリ直下に `ja-JP/` サブディレクトリを作成
- ネストされたサブディレクトリの構造を `ja-JP/` 以下に再現する
- 元のファイル名はそのまま保持する（`.ja-JP` サフィックスは付けない）

| 元のファイル | 出力ファイル |
|------------|------------|
| `docs/readme.md` | `docs/ja-JP/readme.md` |
| `docs/guides/setup.md` | `docs/ja-JP/guides/setup.md` |

**出力先ファイルがすでに存在する場合、そのファイルの翻訳はスキップする。**

## Step 3: 翻訳対象ファイルのフィルタリング（ディレクトリモードのみ）

Glob ツールを使ってディレクトリ内のファイルを列挙する。

### 翻訳対象の拡張子

`.md`, `.mdx`, `.txt`, `.rst`, `.adoc`, `.json`, `.yaml`, `.yml`, `.toml`, `.html`, `.htm`, `.xml`, `.csv`

### 除外対象

以下に該当するファイル・ディレクトリは常にスキップする:

- ファイル名に `.ja-JP` を含むもの（翻訳済み）
- `ja-JP/` ディレクトリ内のファイル
- `node_modules/`, `.git/`, `dist/`, `out/`, `build/` 内のファイル
- バイナリファイル（`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.svg`, `.ico`, `.webp`, `.woff`, `.woff2`, `.ttf`, `.eot`, `.otf`, `.pdf`, `.zip`, `.tar`, `.gz`, `.7z`, `.mp3`, `.mp4`, `.wav`, `.avi`, `.mov`, `.exe`, `.dll`, `.so`, `.dylib`, `.bin`）
- ロックファイル: `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`
- `.env` ファイル（機密情報を含む可能性がある）
- 隠しファイル（`.` で始まるファイル）— ただしファイルモードで直接指定された場合は翻訳する

## Step 4: 言語検出

各ファイルの内容を Read ツールで読み込んだ後、原文の言語を判定する。

1. **日本語判定**: ひらがな（\u3040-\u309F）、カタカナ（\u30A0-\u30FF）、漢字（\u4E00-\u9FFF）がテキスト部分の大半を占める場合は日本語とみなす
2. **すでに日本語の場合**: 「このファイルはすでに日本語です。スキップします: <ファイルパス>」と報告してスキップ
3. **その他の言語**: 英語、中国語（簡体字/繁体字）、韓国語、その他の言語を自動検出し、日本語に翻訳する
4. **検出結果の報告**: 翻訳開始時に「検出された言語: <言語名>」をユーザーに報告する

## Step 5: ファイル種別ごとの翻訳ルール

### Markdown (.md, .mdx)

**翻訳する:**
- 本文テキスト、見出し、リスト項目、表のセルの内容
- YAML frontmatter の値
- HTML 属性の `alt`, `title`

**翻訳しない（そのまま保持）:**
- コードブロック (```) 内のコード
- インラインコード (`) 内のコード
- URL、ファイルパス
- YAML frontmatter のキー名
- HTML タグ自体、クラス名、ID
- 画像パス、リンク先URL

Markdown の書式（見出しレベル、箇条書き、番号付きリスト、テーブル構造）を完全に保持する。

### JSON (.json)

**翻訳する:**
- 文字列値のうち、人間が読むテキスト（ラベル、説明文、メッセージ等）

**翻訳しない:**
- オブジェクトのキー名
- URL、ファイルパス、メールアドレス
- 日付文字列、数値文字列
- プログラム的な識別子（enum値、ID等）
- boolean 値、null 値

JSON の構造とインデント（元のファイルのインデント幅）を完全に保持する。

### YAML (.yaml, .yml)

- JSON と同様のルールを適用する
- YAML のコメント内のテキストも翻訳する
- アンカー (&) とエイリアス (*) はそのまま保持する

### HTML (.html, .htm)

**翻訳する:**
- テキストノードの内容
- `alt`, `title`, `placeholder`, `aria-label` 属性の値

**翻訳しない:**
- `<script>` タグ内、`<style>` タグ内
- HTML タグ構造、クラス名、ID

### プレーンテキスト (.txt, .rst, .adoc)

- 全文を翻訳する
- 空行による段落分けを保持する
- reStructuredText / AsciiDoc の書式記号はそのまま保持する

### CSV (.csv)

- ヘッダー行（1行目）を翻訳する
- データ行のうち、テキストカラムを翻訳する（数値、日付、コードはそのまま保持する）
- CSV のデリミタとクオート形式を保持する

### XML (.xml)

- テキストノードの内容を翻訳する
- 属性値のうち、人間が読むテキスト（label, description, title 等）は翻訳する
- タグ名と構造はそのまま保持する

### TOML (.toml)

- JSON と同様のルールを適用する
- コメント内のテキストも翻訳する

## Step 6: 翻訳品質ルール

1. **自然な日本語**: 直訳ではなく、自然で読みやすい日本語にする
2. **技術用語**: 一般的にカタカナ表記される用語はカタカナで表記する（例: Repository → リポジトリ, Component → コンポーネント）
3. **固有名詞**: 製品名、サービス名、ブランド名は翻訳しない（例: GitHub, React, TypeScript）
4. **略語・頭字語**: API, URL, HTML, CSS, CLI 等はそのまま保持する
5. **一貫性**: 同じ用語は文書全体で統一した訳語を使う
6. **敬体**: 文末は「です/ます」調で統一する（ただし元の文書がカジュアルな場合はそれに合わせる）
7. **原文のトーン保持**: 元の文書のフォーマル度やトーンを可能な限り保持する

## Step 7: エッジケースの処理

1. **空ファイル**: 「ファイルが空です。スキップします: <パス>」と報告してスキップ
2. **大きなファイル** (2000行以上): Read ツールの offset/limit パラメータを使って分割読み込みし、分割して翻訳・結合する
3. **混合言語ファイル**: 日本語と他言語が混在している場合、日本語以外の部分のみ翻訳する
4. **出力先がすでに存在する場合**: AskUserQuestion ツールでユーザーに上書き確認を求める
5. **文字エンコーディング**: UTF-8 を前提とする。Read ツールで読み込めない場合はスキップする
6. **翻訳不要なコンテンツのみのファイル**: コードのみ、URL一覧のみなど翻訳対象テキストがない場合は「翻訳対象テキストがありません」と報告してスキップ

## Step 8: 完了報告

翻訳完了後、以下のフォーマットでユーザーに報告する:

```markdown
## 翻訳完了レポート

| 項目 | 値 |
|------|-----|
| 原文言語 | 英語 (English) |
| 翻訳ファイル数 | 5 |
| スキップ数 | 2 |

### 翻訳されたファイル
- `docs/ja-JP/readme.md`
- `docs/ja-JP/guide.md`

### スキップされたファイル
- `docs/logo.png` (バイナリファイル)
- `docs/faq.ja-JP.md` (翻訳済み)
```
