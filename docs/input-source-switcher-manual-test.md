## Windows 手動確認

前提: Windows 10/11、入力言語に英語キーボードと日本語 IME を追加し、`mise run dev` で ReadyType を起動する。

| # | 前提 | 操作 | 期待 | 実績 |
|---|---|---|---|---|
| W1 | 入力ソースが2種類以上 | 設定画面を開く | TSF 入力プロファイルとキーボードレイアウトが表示される | _未実施_ |
| W2 | 自動切替 ON、Windows 用ルール登録済み | 対象アプリの登録済み入力欄へフォーカス | 対応する入力ソースに切り替わる | _未実施_ |
| W3 | W2 の欄で切替後 | Windows の入力切替操作で手動変更 | 手動変更が同一フォーカス中に維持される | _未実施_ |
| W4 | 任意の入力欄 | アプリを切替、別欄へフォーカス | 前面アプリと UI Automation 属性に対応するルールが評価される | _未実施_ |
| W5 | 自動切替 ON | アプリ切替と欄移動を繰り返す | ReadyType の権限要求なしで監視が継続する | _未実施_ |
| W6 | 監視中 | スヌーズ、再開、アプリ終了、ログイン起動 | macOS と同じ設定上の動作になる | _未実施_ |

実機未実施の行は通過扱いにしない。Windows ルールのアプリ ID は実行ファイル名（例: `code.exe`）。
