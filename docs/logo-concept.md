# ReadyType ロゴ・コンセプト

このロゴは、ReadyType の中心価値である **「カーソルを置いた場所に応じて、適切な入力言語へ自然に切り替わる」** を、`カーソル + 2 つの入力状態` で抽象化したデザインである。

## 一言で

> **Focus determines the input.**  
> カーソルを置いた場所に応じて、入力状態が自然に変わる。

ReadyType という名前まで含めるなら、次の意味付けとも相性が良い。

> **The right input, ready where you type.**

## 構造と意味

| 要素 | 造形 | 意味 |
|------|------|------|
| 中央 | 青い `I` 型 | カーソル（Caret / I-beam）＝ **Type** |
| 左右 | Morph した 2 面 | 異なる Input Source 間の **自動切替** |
| 切替後の状態 | （左右のどちらかが「今」） | **Ready** |

ここから、造形として次のように説明できる。

> **Ready + Type = ReadyType**

```text
      Input State A
           ╲
            ╲
             I  ← Cursor / Focus
            ╱
           ╱
      Input State B
```

```text
Language A │ Language B
           ↑
         Focus
```

## 中央：入力カーソル

中央の青い `I` 型は、テキスト入力時の **カーソル（Caret / I-beam）** を表す。

ReadyType は単なる「日本語 ⇄ 英語切替アプリ」ではなく、

> **どの入力欄にフォーカスしているか**

が切り替えの起点である。

ロゴの中心にカーソルを置くことで、ReadyType 固有の「入力欄・フォーカス」という概念を表している。

## 左右：異なる入力状態

左右の 2 つの面は、**異なる Language / Input Source の状態** を表す。

青と紫という異なる色にすることで、例えば次のような切り替えを示す。

```text
日本語 ↔ English
English ↔ 한국어
日本語 ↔ 한국어
...
```

重要なのは、`A` や `あ` を使っていないことである。  
そのためロゴ自体は **特定の 2 言語に依存しない**。N 言語対応に広げても、そのまま使える。

## Morph した形：自動切り替え

左右を単純な四角形ではなく、**内側へ滑らかに変形する形** にしているのも意図がある。

これは、

> Input Source A → Input Source B

という単純な「手動 Switch」ではなく、

> **フォーカスする場所によって入力状態が自然に Morph する**

ことを表現している。

矢印 `⇄` を使わなかったのもこのためである。  
`⇄` だと「ユーザーが切り替える」印象が強いが、ReadyType の価値は **ユーザーが切り替える必要そのものをなくす** ことにある。

## 左右対称

左右の状態に優劣をつけず、対称構造にしている。

つまり、

> 「日本語が基本で英語へ切り替える」

ではなく、

> **現在のコンテキストに適した Input Source が Ready になる**

という考え方である。グローバル展開するときにも都合が良い。

## 設計上の利点

`A ⇄ あ` のような記号的 2 言語切替よりも、次を同時に満たせる点がこのロゴの強みである。

1. ReadyType 固有の **「入力欄（フォーカス）を起点に Input Source が変わる」** を表現できる  
2. **特定言語ペアに依存しない**（N 言語対応でもそのまま使える）
